# Let's Warm Up

**Category:** General Skills
**Platform:** CyLab/picoCTF
**Difficulty:** Easy

## Description

Simple hex-to-ASCII conversion warmup. Given a hex byte, find the corresponding ASCII character.

## Solution

`0x70` in hex converts to decimal 112, which is the ASCII code for the lowercase letter `p`.

Wrapped it in the flag format as instructed.

## Flag

```
picoCTF{p}
```

## Takeaway

Basic hex-to-ASCII conversion — every printable character has a corresponding hex/decimal code. `0x70 = 112 = 'p'` in the ASCII table.
